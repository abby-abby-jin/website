# 하나의 성 — 인터랙티브 포트폴리오 (프로토타입)

픽셀아트 성 일러스트를 스크롤로 내려가며 층마다 사는 캐릭터(프로젝트)를 만나는 인터랙티브 포트폴리오 사이트입니다.

## 조작법
- 메인 페이지: 스크롤해서 성을 내려가면 각 층의 캐릭터/프로젝트 이름표가 순서대로 나타남
- 이름표(층)를 클릭 → 해당 프로젝트 상세 화면이 오버레이로 열림
- 영상 캠페인: 중앙 버튼 클릭 또는 `Space` → Working Notes(기획의도·카피) 로 스크롤
- SNS 캠페인: `←` / `→` 또는 마우스 가로 스크롤로 게시물 탐색, 클릭 또는 `Enter` → 카피 전체 보기
- 좌상단 "✕ 성으로 돌아가기" 또는 `Esc`: 오버레이 닫고 성으로 복귀
- 우상단 🔈 아이콘: 앰비언스 사운드 on/off (합성음, 게이트 아님)

## 현재 상태 — 프로토타입
- 성에는 실제 콘텐츠 2개(빙그레 영상 캠페인, 氷어공주 SNS 캠페인)만 배치, 나머지 층은 공실(빈 창문)로 표시
- 픽셀아트 성 일러스트는 손으로 그린 SVG (이미지 생성 도구 없이 제작)
- 실제 이미지/영상 에셋 — 기획안 PDF 속 샘플 카피 텍스트만 반영, 비주얼은 저작권 이슈로 자리표시자 사용
