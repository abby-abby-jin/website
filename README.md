# 하나의 성 — 인터랙티브 포트폴리오 (프로토타입)

층마다 다른 캠페인/캐릭터가 사는 성 컨셉의 인터랙티브 포트폴리오 사이트입니다.

## 조작법
- 로비에서 `↑` / `↓` : 다음 층(프로젝트)으로 이동 (순서는 강제랜덤)
- 영상 캠페인 층: 중앙 버튼 클릭 또는 `Space` → Working Notes(기획의도·카피) 열람
- SNS 캠페인 층: `←` / `→` 로 게시물 탐색, 클릭 또는 `Enter` → 카피 전체 보기
- 좌상단 🏰 아이콘: 언제든 로비로 복귀
- 우상단 🔈 아이콘: 앰비언스 사운드 on/off (합성음, 게이트 아님)

## 현재 상태 — 프로토타입
아래 항목은 아직 기획 얼라인이 끝나지 않아 임시값으로 채워져 있습니다. (`선진이 홈페이지 기획 - 얼라인 정리.md` 12번 항목 참고)
- 메인 허브(로비) 비주얼 — CSS로 만든 임시 골드톤 타워, 실제 후보 3안 중 미확정
- SNS 챔버 배경 — 임시 그라디언트 플레이스홀더
- SNS 챔버 인터랙션 — 1안(캐러셀형) 기준으로 구현, 2안 미검토
- 실제 이미지/영상 에셋 — 기획안 PDF 속 샘플 카피 텍스트만 반영, 비주얼은 저작권 이슈로 자리표시자 사용
- 프로젝트 써머리 페이지 — 별도 제작 예정, 이번 빌드에는 미포함
